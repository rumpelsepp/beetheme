{{- /* Outbound links open in a new tab and carry a trailing "external link" icon (Bootstrap Icons). A non-breaking space sits between the link text and the icon (so the icon never wraps onto its own line); a negative right margin on the icon pulls whatever follows the link — a space, or a sentence-ending period — back tight against the glyph. The icon is aria-hidden; the meaning is carried by the visually-hidden note. No trailing newline / whitespace below: a render hook emits the template verbatim, so a stray newline would surface as a space after every link (e.g. before a sentence-ending period). */ -}} {{- $isExternal := strings.HasPrefix .Destination "http" | and (not (strings.HasPrefix .Destination site.BaseURL)) -}} {{ .Text }}{{- if $isExternal }}  (externer Link, öffnet in neuem Tab){{ end -}} {{- "" -}}
